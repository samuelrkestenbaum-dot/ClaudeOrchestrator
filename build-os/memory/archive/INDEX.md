>
> WHAT IS GUARANTEED, AND BY WHOM. Every write this tool makes to this file
> and to the archive files beside it is refused unless the bytes already on
> disk are preserved exactly, so a re-run can only add rows and a second run
> over the same content is a verified no-op. That is a property of THIS TOOL,
> not of this directory: `build-os/memory/archive/` is not ignored, but a file
> written here starts out untracked, so nothing under it has
> version-control backing until it is committed. Anything else that writes
> here can remove it. `git status` DOES show the directory appear, as at
> most one `??` line — but that one line reads the same whether a file inside
> was added, rewritten, or removed, so an overwrite in place is invisible
> there. Removing the whole directory is not: the `??` line disappears.
>
