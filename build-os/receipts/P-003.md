## Why
P-002 labelled npx/uvx success in an **ephemeral container** as "Installed +
working" / "Installed, needs restart". That overstated reality: nothing was
persistently installed on the user's host or globally in Claude Desktop, and no
fresh-session activation test was run. This receipt corrects the records.

## Status semantics (now used everywhere)
- **ACTIVE** — verified in a *newly started normal* Claude Code session.
- **DURABLY CONFIGURED** — committed config can reconstruct it; not active until restart/approval.
- **RUNNABLE ON DEMAND** — verified via npx/uvx in *this ephemeral container*; NOT a persistent/global install.
- **DOCUMENTED/OPT-IN** — recipe/guidance only; not installed.
- **NOT INSTALLED/BLOCKED** — unavailable, ambiguous, or intentionally withheld.

**Rule added:** never call npx/uvx success in an ephemeral container "installed"
unless *both* persistent host state *and* a fresh-session activation test are
verified. Keep **installation · configuration · activation · authentication ·
repository rollout** as five distinct states.
