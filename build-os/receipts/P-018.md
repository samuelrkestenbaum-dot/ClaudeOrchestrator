# P-018 — terminal integrity and in-flight output hardening

- Reproduced a false completion when a valid marker appeared before later output.
- A child is now complete only when exactly one valid status marker is the final non-empty
  captured line. Text after it, duplicate markers, malformed markers, and truncated output
  are unconfirmed and return control to the focused parent.
- Replaced unbounded command substitution with a mode-0700 temporary capture directory and
  a streaming limiter that retains at most `HANDOFF_OUTPUT_MAX` bytes while draining output.
- The real child/timeout exit is stored separately; INT/TERM cleanup terminates and reaps the
  active pipeline, restores focused mode, releases the lock, and removes protected artifacts.
- 21st.dev remains absent from the Claude Code MCP registry. No credential or connection was
  invented; the availability-aware fallback remains authoritative.
- Verification: `bash tests/build_os_tests.sh` passes, including terminal-spoof and 200KB
  streaming-output adversarial cases. User-owned `.claude/tdd-guard/` and `.letta/` untouched.

## P-018.1 — Linux portability closure (test harness)

- Symptom: on this Linux cloud/CCR surface the 200KB capture-bound test failed
  (`capture-time bound failed`) while it passed on macOS. Root cause was the **test**, not the
  product: the payload was delivered through an environment variable
  (`MOCK_CHILD_OUTPUT="$(head -c 200000 …)"`), which exceeds Linux `MAX_ARG_STRLEN` (~128KB) and
  makes `execve` fail with *Argument list too long* before the real capture-time bound ever runs.
  macOS has no per-arg cap, so the defect was invisible there.
- Fix (tests only; product implementation unchanged): the mock child now **generates/streams the
  payload internally** — `MOCK_GEN_BYTES` (in-child 200KB) and `MOCK_STREAM_CHUNKS` (continuous
  ~245KB over ~1.2s) — never via env/argv. Both prove the real streaming limiter caps captured
  output at `HANDOFF_OUTPUT_MAX` and emits `OUTPUT TRUNCATED at <N>`.
- Independently confirmed the product bound works on Linux: a child emitting 200KB in-child is
  captured at 1024 bytes with the truncation marker (total capture < 2500 bytes).
- Cross-platform evidence: `bash tests/build_os_tests.sh` → **202 passed, 0 failed** on Linux
  (this surface), deterministic; the same suite passed on the macOS host. `.claude/tdd-guard/`
  and `.letta/` untouched; no product/runtime change, no merge/deploy/PR.
