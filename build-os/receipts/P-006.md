## The five changes
1. **Proportionate routes** (`tool_router.md` table): `Read-only answer / question`,
   `Diagnosis / triage (no edits)`, `Tiny reversible local edit` — none default to
   `builder → qa → reviewer → archivist`; each has a "don't over-orchestrate" gate and an
   escalate-don't-expand rule.
2. **Tool selection ranking**: exact task match > project-local instruction > enabled/live
   evidence > least privilege > lowest orchestration overhead > freshest verified result;
   "use one primary capability unless another has a distinct necessary job."
3. **Availability = live proof**: detector separates *Enabled plugins (settings)* and
   *native user/project* skills/commands/agents from *Plugin-cache candidates (VERIFY LIVE)*;
   cache presence is a candidate, not proof — confirm via a registry/tool call before ACTIVE.
4. **Managed-block replacement**: both installers strip ALL prior BUILD-OS blocks (any
   manager tag) and re-append one fresh block, preserving non-managed content — re-running
   refreshes stale guidance instead of skipping it. (Also de-duplicates accumulated blocks.)
5. **Installer parity**: `install-project.sh` copies all `.claude/hooks/*.sh` (was two named
   hooks), matching `install-global.sh`.
