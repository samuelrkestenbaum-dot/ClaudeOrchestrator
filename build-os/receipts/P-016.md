## Findings fixed
1. **Classifier confused ECC-the-bundle with elliptic-curve crypto.** Replaced the single opaque
   regex with a **maintainable capability registry**: precedence-ordered, per-family `CAP_*`
   ERE patterns walked top-to-bottom by `classify()` (zeroize > ecc > 21st > agent-reach >
   claude-watch > ui-ux-pro-max > focused). Broad *Everything Claude Code* families now route
   `ecc`: Rust ownership/unsafe, Go concurrency/debug, PostgreSQL schema/query, autonomous-agent
   harness/evals, architecture + browser specialists. Existing crypto tokens (ecc/ed25519/ecdsa/
   secp256/curve25519/chrome-devtools) retained. **Conservative:** trivial tasks (list files, doc
   typo, factual "what port does postgres use") stay `focused` — no relaunch.
2. **Inline routing enforced.** `classify` returns distinct `21st` / `agent-reach` /
   `claude-watch` / `ui-ux-pro-max`; `detect` emits a strong **REQUIRED current-surface**
   directive and **never** calls `capability-profile` or launches a child. `prompt-router.sh`
   now prints route-accurate wrappers — a child-handled message only for `ecc`/`zeroize`, an
   explicit "no child was launched" message for inline routes.
3. **Zeroize natural-language coverage expanded** (e.g. "check whether API keys remain in memory
   after use", "verify secrets are cleared from registers and the stack"). Zeroize keeps highest
   precedence (outranks ecc).
4. **Privacy.** The handoff audit log records only `timestamp / route / result / exit / event`
   (a non-reversible 16-hex id) — **never prompt text or cwd**. It is created `0600` and an
   existing `0644` file is tightened to `0600` on every write; old plaintext content is neither
   output nor migrated.
5. **Concurrency.** A portable `mkdir`-atomic lock wraps profile activation + child + restore.
   `HANDOFF_LOCK_WAIT` (default 30s) is configurable; on contention it **fails closed** with a
   clear `RESULT: BUSY` (exit 75) and performs **no profile mutation and no child**. Stale locks
   are detected (PID-liveness via `kill -0`, plus an age fallback `HANDOFF_LOCK_STALE`=1800s) and
   broken safely; the lock is released on `EXIT/INT/TERM`; focused restoration is preserved.
6. **Surface-aware inventory.** `tool_router.md` now distinguishes **Claude Desktop** connector
   verification from the local **Claude CLI**: 21st.dev is a Desktop connector and **absent from

   **v0.4.1** are enabled Claude Code skills/plugins. Stale "host-reported" language removed; no
   cross-surface ACTIVE claim.
7. **skill-budget-audit fixed.** New `--claude-dir` mode reports **installed inventory**
   (de-duped by `installed_plugins.json` installPath) **separately** from the **startup-enabled**
   set (only `settings.json` `enabledPlugins`), and checks **only the enabled set** against

   preserved (now de-dupes cache/marketplace copies; any over-budget note is labelled *installed

## Correction — live-host defect in the enabled-aware audit (finding 7 follow-up)
Live-host verification after installing `1bccbb5` found `skill-budget-audit.sh --claude-dir
"$HOME/.claude"` reported **installed inventory: 0 skills across 0 plugins** despite a real
`~/.claude/plugins/installed_plugins.json` with 25 plugins. **Root cause:** the real schema stores
each `plugins[name]` value as a **LIST of install records** (`[{scope,user,installPath,...}]`),
while the parser only handled a single-dict `meta.get("installPath")` — so every list value was
skipped. **Fix:** a `choose_install_path()` helper now accepts the list schema (plus the dict and
bare-string forms), preferring the current **user**-scope record, then any record whose
`installPath` exists on disk, then the last named path (latest); one path per plugin, still
de-duped globally. Test §21 now seeds the real list schema — including a `big@mkt` entry with a
stale project record + the real user record — and asserts nonzero installed inventory (12), a
correct startup-enabled count (1), and that the legacy dict schema still parses to the same
counts. Suite **186 → 189** green. Installed-vs-enabled separation is unchanged and honest.
