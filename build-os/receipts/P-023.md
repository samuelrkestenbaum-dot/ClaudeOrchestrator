## Delivered

- **`build-os/tools/project-bootstrap.sh` (new).** Resolves the effective project
  (`--target` > `CLAUDE_PROJECT_DIR` > cwd) and installs the **MANAGED** set: agents,
  commands, hooks, `build-os/tools/*.sh` (incl. `capability-profile.sh`, `supervise.sh`,
  `specialist-handoff.sh`, `skill-budget-audit.sh`), `tool_router.md`, `skill_budget.md`,
  `global-claude-md.md`, the managed `CLAUDE.md` block, and `settings.json`
  SessionStart + UserPromptSubmit wiring merged idempotently.
  **PRESERVES:** `current_state.md`, `residue.md`, `packets/`, `receipts/`, product files,
  non-managed `CLAUDE.md` content, and unrelated `settings.json` keys (seeded only when absent).
  **Transactional:** stage → backup → atomic promote → validate → rollback.
  **Safe:** `mkdir`-atomic lock with fail-closed BUSY; no recursive deletion of
  env-controlled paths.
  **Cheap on repeat:** content-hash + source-SHA cache skips redundant work.
  **Auditable:** writes `build-os/.install-manifest.json` (source SHA, runtime version
  `1.0.0`, timestamp, per-file sha256, agents, tools, preserved list).
- **`.claude/hooks/session-start-build-os.sh`.** Invokes the bootstrap (bounded 60s,
  non-fatal) and replaces the unconditional `Orchestrator: ON` with a **verify-driven
  ON/DEGRADED** line naming missing agents/tools, canonical vs installed SHA, bootstrap
  outcome, and an explicit caveat: *file presence is discoverability, not proof of
  callability*.
- **Closed previously-observed omissions:** absent `tools/`, `capability-profile.sh`,
  `supervise.sh`, `skill_budget.md`, `global-claude-md.md`.
- **`README.md`** documents the automatic bootstrap and the MANAGED-vs-PRESERVED rule —
  including that `tool_router.md` is **MANAGED** and refreshed on each bootstrap, so
  project-specific routing belongs in `current_state.md` / `residue.md` or the user-scope
  router, per the 3-tier fallback.
