# EXP-0001 — Conclusion

**`causal effect supported`** — in the direction of **Gravito increasing total model
tokens per durable accepted outcome on the T1 task class**, in this environment.

Median 312,444 tokens (ON) vs 153,611 (OFF): a 50.8% reduction with Gravito OFF,
ranges fully disjoint, uncached comparison agreeing in direction (40.3%), acceptance
5/5 in both arms, no preregistered confound clause fired, verdict produced by a
blinded independent evaluator applying the preregistered mechanical rule and revealed
only after that analysis was committed.

## Scope, stated with the label as the preregistration requires

The supported effect is bounded to: small single-file corrections requiring no suite
execution (the T1 shape), this repository, this model configuration
(claude-haiku-4-5 + claude-sonnet-5, CLI 2.1.222), this headless Bash-denied
permission regime, N=5 pairs. It does not generalize to multi-step or suite-executing
work (T2–T4 produced no numeric data in either arm), to interactive sessions, or to
long-horizon memory-reusing workloads.

## The honest reading for the product

1. The hypothesis under test — "Gravito materially reduces tokens per durable
   accepted outcome" — is **not supported on the one task class this environment can
   measure canonically**; the supported effect there is the opposite, at roughly 2×.
2. This is the loss case the frozen protocol itself predicted ("T1 is the task this
   system loses on"): fixed governance overhead on a task with nothing to govern.
   Evidence that the instrument can return an unflattering verdict is also evidence
   the instrument works.
3. The claim that remains open — untested, not contradicted — is the one the product
   actually sells: that memory, receipts, and handoffs pay for themselves on
   substantive multi-step work. Measuring THAT requires either the suite-execution
   capability (T2–T4 canonical runs) or paired measurement on real long-horizon work.
   The observed weekly usage drop remains prior evidence for it, not proof.
4. Per the operator's freeze rule, nothing was optimized mid-experiment and no
   machinery was altered. Defects discovered during the experiment: none; no run
   required labeling beyond the preregistered fields.

## Follow-up the data itself suggests (recorded for the operator; not acted on)

- The 16-vs-0 tool-failure asymmetry says the installed surface asks the headless
  agent for tools this environment refuses; a lighter or environment-aware install
  profile is a measurable next experiment, not a tweak to make quietly.
- The decisive missing evidence is a T2/T3/T4-class paired experiment, which is
  blocked on the same capability gap as the benchmark baseline (headless Bash
  denial). If that gap ever closes, EXP-0002 on the substantive tasks is the
  experiment that tests what Gravito is actually for.
