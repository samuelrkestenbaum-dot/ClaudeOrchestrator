1. EXP-0011 is treated as an **exploratory three-way systems study**, not a
   confirmatory representation test.
2. The **1,536-byte rules cap vs 6,144-byte skills cap is a prominent causal

   survives the cap asymmetry** — e.g. it appears in arms/positions where
   installed bytes were comparable, or persists after the byte-budget-matched

## Sequence after EXP-0011 closes, before any large measured study

1. **Calibration gate first** (EXP-0012, already built, rule precommitted):
   serial-vs-wide equivalence. No parallel timing is used in any measured
   study until it passes.
2. **Three staged studies replace the next omnibus 60-arm confirmation:**
   - **A. Representation** — verified rules vs verified procedural skills,
     12–16 matched pairs, **identical installed token/byte budget**, no
     progressive-disclosure advantage on either side. Primary: acceptance.
     Secondary: exact tokens, elapsed.
   - **B. Progressive disclosure** — same underlying skill content, fully
     injected vs tiny index + on-demand loading. Measured: total
     provider-native token categories, unnecessary loads, acceptance,
     latency.
   - **C. Compounding** — only after A and B have identified the best
     representation and delivery mechanism: native vs accumulated verified
     skills across positions 1–5, testing whether marginal benefit grows or
     degradation is avoided.
3. **Harness reliability qualification before each measured study** — a
   short qualification run with a frozen maximum invalid-run rate and a
   stopping rule, both stated before data.
4. **Repository/parser suitability stays explicit.** The earlier
   583 KB → 6,622-byte result (operator-cited, with recorded parser-free
   coverage) is NOT usable as lossless semantic compression or total-token
   evidence.
5. **Metric separation preserved:** exact provider token categories,
   treatment preparation/compilation overhead, acceptance, intervention,
   regression, and elapsed time are each reported; speed and compression
   remain separate conclusions.
6. **No successor study is launched, frozen, or published from this
   document.** It exists for review after EXP-0011's frozen read.
