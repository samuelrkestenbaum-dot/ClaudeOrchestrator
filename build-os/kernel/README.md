# Build OS — cross-surface memory kernel (v0)

> **THE ONE PROPERTY THIS LAYER EXISTS TO PROVE.** Claude closes work into
> governed project memory, and a second AI surface consumes that project state
> **without anybody copying the Claude transcript**. Everything in this directory
> serves that sentence; nothing here is infrastructure for its own sake.

## What is canonical, and what is a projection

**The eight `.tsv` files in this directory are the ONLY canonical truth.** Each
store has exactly one canonical representation — one file, one row shape, one
writer. `build-os/tools/memory-kernel.sh` is that writer, and it is the only
thing in the repository licensed to append to them.

**Everything under `exports/` is a PROJECTION.** It is generated from the stores,
it is regenerated byte-for-byte by `memory-kernel.sh reconcile`, and it is
**never** the place a fact is edited. A projection edited by hand does not become
a second opinion — it becomes a refusal (`PROJECTION-DIVERGED`), because this
tree already carries `DEFECT-0003-duplicate-semantic-truth` and one instance of
that class is enough. The direction is one-way and mechanically enforced:

```
canonical store  ->  generated projection  ->  parsed back  ->  same id, version and hash
```

`memory-kernel.sh validate` additionally refuses a canonical `payload_ref` that
points **into** `exports/`. Canonical truth may not be stored inside its own
shadow.

## The stores

| file | id prefix | what it holds |
|---|---|---|
| `namespaces.tsv` | `NS-` | the isolation hierarchy |
| `actors.tsv` | `ACT-` | logical role and execution surface, kept distinct |
| `memory_objects.tsv` | `OBJ-` | the typed object envelope, one row per version |
| `memory_events.tsv` | `EVT-` | the append-only, digest-chained ledger |
| `memory_relationships.tsv` | `REL-` | typed edges between objects |
| `memory_artifacts.tsv` | `ART-` | the bridge to files already in this tree |
| `memory_handoffs.tsv` | `HOF-` | structured cross-surface handoffs |
| `memory_context_packages.tsv` | `CTX-` | immutable compiled context, version-bound |

Every store is tab-separated, one record per line, `-` for an absent value and
`;` between the members of a list field. **A row count is `grep -c '^PREFIX'`,
never `wc -l`** — a final row with no trailing newline is a row, and counting
lines would lose it.

## The namespace hierarchy

```
organization -> workspace -> project -> repository -> branch -> packet -> execution
```

Reads and writes are scoped to the **closure** of a namespace: that namespace
and its descendants. An actor declared in `NS-0006` may act in `NS-0006` and
below and **nowhere else**. A read that reaches sideways — into a sibling
project — is refused with `NAMESPACE-REFUSED` rather than filtered, because a
silent filter and an empty result are indistinguishable to the caller.

## Actor identity is not surface identity

```
logical role      gravito.builder                  carries responsibility
execution surface claude.cowork.session.ramhds     identifies who executed it
```

Both are recorded on every write. An event whose `surface_id` is not the
`surface_instance` its actor declares is refused (`SURFACE-IDENTITY`): a role
cannot borrow a surface it never ran on.

## Truth states are not evidence

Every object carries a `truth_state` from

```
observed · reported · inferred · decided · verified · refuted · unknown
```

and `observed`, `verified` and `refuted` **require at least one resolvable
evidence reference**. That is the same discipline the decision store already
enforces with `<value>@<provenance>`: a model-generated inference may be
recorded, and it may not be recorded as an observation. `decided` requires an
`authority_ref` for the same reason — a decision with no authority behind it is
an opinion.

## Citations are anchors, not line numbers

Artifacts bridge to files that already exist in this repository, and they do it
through the anchor scheme `PACKET-0029` shipped
(`scan-controls.sh anchors`): an artifact names an **anchor id**, the anchor
resolves **by content**, and the line number is a return value rather than an
identity. **No file in this directory contains a `path:line` token**, so nothing
here decays when a line moves.

## The invariant that matters most

> **A context package that PARSES but refers to the WRONG VERSIONS is REFUSED.**

`resolvability is not identity`, applied to memory. A context package records the
exact `(object_id, version)` pairs it was compiled from. When a source object
advances a version, that package does not quietly become a description of the
new state — it becomes **STALE**, `read-context-package --as-current` refuses it
(`PACKAGE-STALE`), and the only way to get a current package is to compile a new
one.

## What v0 does NOT contain

No database, no cache, no object storage, no vector search, no embeddings, no
graph engine, no subscriptions, no write access for any surface other than the
governed adapter, no learned ranking, and **no learned policy holding any
authority whatsoever** — retrieval is mandatory-inclusion, then one hop of
relationship expansion, then evidence and authority relevance, then recency, and
that order is fixed in code rather than fitted.
